# Pilot 7 – Digital dialog mellom barnehage/skole og hjemmet

Pilot i SAMT-BU (Sammenhengende tjenester for barn og unge). Piloten skal finne ut hvordan eksisterende løsninger for
kommunikasjon mellom hjem, barnehage, SFO og skole kan samhandle bedre, slik at foresatte kan velge hvordan de vil motta
og følge opp kommunikasjonen. Utgangspunktet er gjenbruk, samhandling og åpne grensesnitt, ikke en ny app.

Piloten bygger på case 11: [Digital dialog mellom barnehage/skole og hjemmet](https://docs.samt-bu.no/behov/use-cases/11-digital-dialog-hjem/).
